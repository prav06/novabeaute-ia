NovaBeauté
Prototype expérimental
Projet éducatif — non validé cliniquement. Ce site s'appuie sur un modèle entraîné sur le jeu de données public HAM10000, dans un cadre de démonstration technique. Il ne remplace pas un avis médical.

Repérage de grains de beauté — démo technique

Cette interface envoie une photo à un modèle de classification entraîné localement (voir le dépôt GitHub) et retrouve les images les plus similaires dans la base de référence.

Nécessite l'API locale lancée sur http://localhost:8000 (voir README).

NovaBeauté — projet portfolio, dataset HAM10000 (CC-BY-NC), non destiné à un usage clinique.
